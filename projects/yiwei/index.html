一苇 · Yiwei

一苇 · Yiwei

以阅读器为核心、Local-first、跨平台、插件化的现代阅读平台。本地电子书与网络小说都能读，支持书源、AI、OCR、翻译、批注与多种同步后端。

项目目标

项目以 Readest 为上游基础改造为自有产品（应用标识 com.yiwei.reader、深链 yiwei://），不是 EPUB 阅读器换皮。真正的资产是三样：

  1. 阅读体验：排版、字体、翻页、批注、跨设备阅读连续性
  2. 开放协议：Document / Annotation / Sync / Plugin / Provider
  3. 生态：书源、AI Provider、OCR Provider、词典、TTS、同步后端、插件

主要功能

  • 书籍格式：EPUB、PDF、MOBI / AZW / AZW3、FB2、CBZ / ZIP、TXT、Markdown
  • 阅读体验：翻页 / 滚动双模式、排版与主题自定义、代码语法高亮、阅读标尺与逐段模式、速读（RSVP）、并行阅读、E-ink 模式、键盘导航与屏幕阅读器
  • 标注与笔记：高亮 / 书签 / 笔记、笔记本与导出、触控笔手写（上游在建）
  • 查询与翻译：内置与自定义词典（Yomitan ZIP / RDICT / StarDict 等）、Wikipedia / Wiktionary、DeepL / Google / Azure / Yandex 全文翻译、AI 助手（自备 key）
  • 朗读与有声书：Edge TTS / 系统 TTS / Web Speech、变速与句词高亮、EPUB 3 Media Overlay 跟读、本地有声书配对、Audiobookshelf
  • 书库与集成：OPDS / Calibre、网页剪藏与网页小说抓取、浏览器扩展、LocalSend 局域传输、RSS 订阅转书、Readwise / Notion / Hardcover / BookOrbit
  • 同步与备份：跨设备同步进度 / 标注 / 书籍文件（Google Drive / OneDrive / WebDAV / S3 / iCloud，自备配置）、KOReader 同步（KOSync）、本地备份
  • 平台：Windows / macOS / Linux / Android / iOS / Web（PWA）

技术架构

Tauri 2 + Rust Core（crates/）+ WASM，Local-first 数据模型，SQLite 存储，AGPL-3.0 开源。
