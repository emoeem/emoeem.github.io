Yazi 插件使用指南

本文档记录当前 Yazi 插件配置、快捷键、依赖和维护注意事项。

更新时间：2026-08-04
适用版本：Yazi 26.5.6

本次新增插件

插件 功能 快捷键
git.yazi 在文件列表中显示 Git 状态标记 自动生效
smart-filter.yazi 连续过滤，自动进入唯一目录 f
lazygit.yazi 在当前 Git 仓库打开 Lazygit g l
pref-by-location.yazi 按目录保存排序、行模式和隐藏文件设置 自动保存
projects.yazi 保存和恢复多个标签页组成的项目工作区 P 前缀
what-size.yazi 计算选中项或当前目录的总大小 m d / m D

智能过滤

按 f 打开居中的智能过滤输入框。

  • 输入时实时过滤。
  • 只剩一个目录时自动进入。
  • 按回车打开唯一文件或进入目录。
  • 在插入模式下先按一次 Esc 返回普通输入模式，再按一次关闭过滤。

当前保留了本地定制：过滤输入框显示在屏幕中央。

Git 与 Lazygit

git.yazi 会自动检查当前 Git 仓库，并在文件列表中显示：

  • 修改文件
  • 新增文件
  • 未跟踪文件
  • 删除文件
  • 冲突文件
  • 被忽略文件

在 Git 仓库中按 g l 打开 Lazygit。系统已经安装 git 和 lazygit，
不需要额外依赖。

目录偏好

修改以下设置后，pref-by-location 会自动保存当前目录的偏好：

  • .：显示或隐藏点文件
  • m s：显示大小
  • m p：显示权限
  • m b：显示创建时间
  • m m：显示修改时间
  • m o：显示所有者
  • m n：不显示附加信息
  • , 开头的全部排序快捷键

管理快捷键：

快捷键 功能
, t 启用或停用目录偏好自动保存
, R 删除当前目录的自定义偏好，恢复全局设置

偏好保存在：

~/.config/yazi/pref-by-location

项目工作区

项目工作区会保存当前打开的全部标签页、标签页目录、活动标签页和标签页名称。

快捷键 功能
P s 选择槽位并保存当前工作区
P l 加载已保存的工作区
P P 加载最近保存或加载的工作区
P d 删除一个工作区
P D 删除全部工作区

保存时先选择一个数字或字母槽位，再输入项目名称。

当前插件版本要求初始化时显式传入空配置：

require("projects"):setup({})

本地还优化了空槽位菜单说明，使其显示
Save project to slot X，而不是含糊的 callback。

目录大小

快捷键 功能
m d 计算选中项的总大小；没有选择时计算当前目录
m D 计算大小并复制结果到系统剪贴板

结果会同时显示在通知和状态栏中。大型目录需要等待 Yazi 完成递归计算。

插件维护

查看当前安装的插件：

ya pkg list

升级插件：

ya pkg upgrade

smart-filter.yazi 和 projects.yazi 包含本地体验优化。升级时如果 Yazi
提示插件内容被修改，请先检查差异，不要直接使用 --discard，否则会丢失：

  • smart-filter 的居中输入框
  • projects 的项目槽位菜单说明

检查配置是否能正常加载：

yazi --debug

尚未安装

当前快捷键文件中仍然存在以下插件入口，但插件尚未安装：

插件 现有快捷键 状态
whoosh.yazi [、]、} 等书签键 未安装
recycle-bin.yazi R b 未安装，系统也没有 trash-cli

使用这些快捷键前，需要先安装对应插件和依赖；否则 Yazi 会提示找不到插件。
