voicefox 0.3.15 快捷键完整参考

当前文档对应 voicefox-old 旧版 TUI + 新功能整合线。快捷键支持通过 [keybindings] 自定义；运行时按 ? / F1 可查看当前实际生效的配置。

全局

键 动作
1~`8` 队列/搜索/排行榜/歌单/收藏/历史/本地/设置
Tab / Shift+Tab 下一页 / 上一页
Space 播放/暂停
n / b 下一首 / 上一首
m 切换播放模式
] / [ 队列页快进/后退 5 秒；搜索页切换音源
. / , 音量 +5% / -5%
Ctrl+L 收藏当前播放歌曲
Ctrl+S 下载当前歌曲；队列页下载选中歌曲
Ctrl+O 下载面板
Ctrl+R 重绘并重传封面
Esc 取消/返回
? / F1 快捷键帮助
q 退出

队列

键/操作 动作
↑ / k 上一项
↓ / j 下一项
g / Home 第一项
G / End 最后一项
Ctrl+U / PageUp 上翻页
Ctrl+D / PageDown 下翻页
Enter 播放选中歌曲
Shift+↑ / Shift+↓ 上移/下移歌曲
d / Delete 移除歌曲
Shift+D 清空队列
/ 队列筛选（歌曲名/歌手/专辑）
Enter 确认筛选
Esc 退出并清空筛选
Backspace 删除筛选字符
V 歌词普通/全屏切换
鼠标左键拖动 队列排序
鼠标右键 歌曲菜单

队列页裸 ↑/↓ 专用于列表选择；音量方向键使用 Ctrl+↑/↓。

搜索

键 动作
i / / 输入搜索
Enter 搜索
↑/k、↓/j 导航
g/G、Home/End 首项/末项
Ctrl+U/Ctrl+D 翻页
Enter/l 播放
a/A 加入队尾/下一首
D 下载
f 收藏
←/[、→/] 上一个/下一个音源
v 音源版本列表
@ 追搜歌手；B站结果按 UP 主处理
# 追搜专辑
再按相同 @/# 取消条件并恢复基础关键词
Esc 退出输入/弹层

排行榜

↑/k、↓/j 导航；Enter/l 进入/播放；g/G 首末项；Ctrl+U/Ctrl+D 翻页；a/A 加入队尾/下一首；D 下载；f 收藏；Esc 返回。

热门歌单

←/→ 切换音源；↑/k、↓/j 导航；Enter/l 进入/播放；a/A 入队；f 收藏；/ 或 s 搜索歌单；r 刷新；Esc 返回。

收藏

↑/k、↓/j 导航；Enter/l 播放；g/G 首末项；Ctrl+U/Ctrl+D 翻页；a/A 入队；s 排序；/ 筛选；d/Delete 取消收藏；f 收藏切换。

历史

↑/k、↓/j 导航；Enter/l 播放；g/G 首末项；Ctrl+U/Ctrl+D 翻页；a/A 入队；s 排序；/ 筛选；Delete 删除；Shift+X 清空历史。

本地音乐

↑/k、↓/j 导航；Enter/l 播放；a/A 入队；s 排序；r 重扫；/ 筛选；d/Delete 删除文件并确认。

下载面板

Ctrl+O 打开/关闭。↑/k、↓/j 导航；g/Home、G/End 首末项；Ctrl+U/Ctrl+D 翻页；c/d/Delete 取消活动下载或移除已结束记录；x 清理已结束任务；Esc 关闭；鼠标右键取消/删除当前记录。

底部会显示 ↑↓选择 · Del/右键删除。

歌手/专辑详情

右键歌曲 → 查看歌手/查看专辑。↑/k、↓/j 导航；Enter 播放/进入；a/A 入队；f 收藏；g/G 首末项；Ctrl+U/Ctrl+D 翻页；Esc 返回。

多歌手歌曲会分别显示 查看歌手：A、查看歌手：B，不会再要求把整个合作艺人字符串作为一个歌手查询。

设置

设置页使用 k/j 或方向键导航，Esc 返回。默认设置动作避免占用 1~`8` 页面导航键：

键 动作
F1~`F10` 播放速度、音频设备、ReplayGain、声道、预放大、平衡、削波保护、淡入、淡出、EQ
Shift+F1 / Shift+F2 执行淡入 / 淡出
Shift+F3 / Shift+F4 A-B 起点 / 终点
Shift+F5 清除 A-B 循环
Shift+F6 / Shift+F7 导出 / 导入用户数据
Shift+F8 导入外部歌单

快捷键配置格式

支持：j、Space、Enter、Esc、Up、Down、Left、Right、Home、End、PageUp、PageDown、Delete、F1~`F12，以及 Ctrl+/Shift+/Alt+` 组合。

示例：

[keybindings.global]
quit = "Ctrl+q"
play_pause = "Space"
next_track = "n"
prev_track = "b"

[keybindings.pages.main]
list_select_up = "Up"
list_select_down = "Down"
list_activate = "Enter"

修改配置后重新启动 voicefox 即可加载。当前配置与默认值合并，未填写的动作继续使用默认绑定。
