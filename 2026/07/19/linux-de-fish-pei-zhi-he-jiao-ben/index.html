1. 文件结构概览

~/.config/fish/
├── config.fish              ← 主配置文件（你日常编辑的入口）
├── secrets.fish             ← 敏感变量（API Key 等，不要提交到 Git）
├── fish_variables           ← Fish 全局变量持久化存储（自动管理，一般不需要手动编辑）
├── config.fish.bak          ← 旧版配置备份（可忽略）
├── conf.d/                  ← Fish 启动时自动 source 的补充配置
│   └── (已清空，迁移文件已删除)
├── completions/             ← 自定义命令补全定义
│   ├── fzf-fftools.fish     ← FFmpeg 工具箱补全
│   ├── fzf-pkg.fish         ← 包管理工具补全
│   ├── fzf-add-watermark.fish
│   ├── fzf-burn-subs.fish
│   ├── fzf-compress-video.fish
│   ├── fzf-concat-video.fish
│   ├── fzf-convert-media.fish
│   ├── fzf-extract-audio.fish
│   ├── fzf-merge-av.fish
│   ├── fzf-mute-video.fish
│   ├── fzf-speed-video.fish
│   ├── fzf-trim-video.fish
│   ├── fzf-validate-media.fish
│   └── fzf-video-to-gif.fish
├── functions/               ← Fish 自动加载的函数目录（当前为空，函数都写在 config.fish 里）
└── README.md                ← 本文档

外部依赖配置：
~/.config/starship.toml      ← Starship 提示符主题
~/.config/atuin/config.toml  ← Atuin 历史搜索配置

加载顺序

config.fish 主配置
  ├── 1. Starship 提示符初始化
  ├── 2. Zoxide 目录跳转初始化
  ├── 3. 环境变量 + secrets.fish
  ├── 4. fzf 模糊查找初始化
  ├── 5. Atuin 历史搜索初始化（接管 Ctrl+R）
  ├── 6. direnv / pay-respects 钩子
  ├── 7. 缩写（abbr）定义
  ├── 8. 自定义函数
  ├── 9. PATH 配置

       ├── done 长命令通知
       ├── eza 别名（ls/la/ll/lt 等）
       ├── 系统管理别名（update/mirror/cleanup 等）
       ├── !! / !$ 历史展开支持
       ├── history 函数（带时间戳）
       └── backup / copy 函数

6. 自定义函数

yy — Yazi 终端文件管理器

yy              # 在当前目录打开 yazi
yy /path/to/dir # 在指定目录打开

特点：退出 yazi 后，Shell 会自动切换到你最后浏览的目录。不需要手动 cd。

cat — 智能 cat（bat 替代）

cat file.txt     # 输出到终端 → 用 bat（语法高亮 + 行号）
cat file.txt | wc -l  # 管道中 → 用系统 cat（避免 bat 干扰管道）

设计原理：Fish 的补全系统内部会调用 cat 读取缓存文件，如果 cat 被 alias 成 bat --number，补全会出现乱码。这里用函数包裹，仅在交互式终端输出时使用 bat，管道和脚本中保持原始 cat 行为。

man — 智能 man（tldr 优先）

man tar          # 优先显示 tldr 速查表
man 3 printf     # 带章节号 → 直接用系统 man
man              # 无参数 → 直接用系统 man

设计原理：tldr 输出简洁实用，日常 80% 的场景够用。带章节号（如 man 3 printf）或 tldr 查不到时自动回退到完整 man page。

敏感变量（secrets.fish）

API Key 等敏感信息存放在 ~/.config/fish/secrets.fish 中，通过 source 引入。不要将此文件提交到 Git 仓库。

# 如果使用 Git 管理 dotfiles，在 .gitignore 中添加：
echo "secrets.fish" >> ~/.config/fish/.gitignore

当前 secrets.fish 中存放的变量：

  • STRIX_LLM — LLM 模型标识
  • LLM_API_KEY — LLM API 密钥

如需添加新的敏感变量，直接编辑 secrets.fish 即可，无需修改 config.fish。

9. 可选增强与启用方法

delta — Git Diff 美化

delta 提供语法高亮、侧边并排对比、行号等特性，比默认的 git diff 美观得多。

# 一次性配置（写入 ~/.gitconfig，无需每次设置）：
git config --global core.pager delta
git config --global interactive.diffFilter "delta --color-only"
git config --global delta.line-numbers true
git config --global delta.side-by-side true
git config --global delta.syntax-theme TwoDark

xh — 现代 HTTP 客户端

xh 是 HTTPie 的 Rust 重写，比 curl 更直观。需要先安装：sudo pacman -S xh

# 安装后，取消 config.fish 第 227-237 行的注释即可启用以下缩写：
req https://api.example.com    # 发送 GET 请求
get https://api.example.com    # 明确 GET
post https://api.example.com name=foo  # POST 表单

Atuin 目录过滤模式

默认 Atuin 搜索全局历史。如果希望优先显示当前目录下的命令：

# 在 config.fish 第 42 行取消注释：
set -gx ATUIN_FILTER_MODE "directory"

pay-respects 触发词

默认按 f + Enter 触发纠错。如果更习惯 fuck：

# 在 config.fish 第 101 行取消注释：
set -gx PAY_RESPECTS_ALIAS "fuck"

开启终端欢迎信息（fastfetch）

当前已禁用自动运行的 fastfetch。如需恢复：

# 删除 config.fish 第 189 行的覆盖：
# function fish_greeting; end

10. 常见问题

Q: 为什么不用 alias cat=bat 而是用 function 包裹？

Fish 的补全系统内部（__fish_cached 等）会调用 cat 读取缓存文件。如果 cat 被 alias 成 bat --number，缓存输出会被加上行号，导致 pacman 等补全出现乱码。用 function 包裹可以在终端输出时使用 bat，在管道/脚本中回退到原始 cat。

Q: 为什么 Alt+C 被禁用了？

你的窗口管理器是 Niri，Alt 键作为 Mod 键使用。fzf 默认将 Alt+C 绑定为目录跳转快捷键，会与 Niri 冲突，因此在配置中显式解绑。

Q: abbr 和 alias 有什么区别？为什么混用？

abbr alias
展开时机 键入时（按空格/回车前） 执行时
脚本兼容 ❌ 脚本中不展开 ✅ 在脚本中也能替换
历史记录 保存展开后的完整命令 保存别名本身
适用场景 交互式终端日常使用 需要脚本兼容的场景

本配置中，高频交互命令用 abbr（Git 操作等），CachyOS 预设的兼容性命令用 alias（ls/cd 等）。两者共存互不冲突——abbr 优先展开，如果展开后的词恰好是 alias 名，还会再被 alias 替换。

Q: update 是什么？和 sudo pacman -Syu 有什么区别？

update（CachyOS alias）= sudo cachyos-rate-mirrors && sudo pacman -Syu，在系统更新前先测速排序镜像源，确保下载速度最快。比单纯的 pacman -Syu 多一步镜像优化。

Q: yy 和直接运行 yazi 有什么区别？

直接运行 yazi 退出后终端还在原来的目录。yy 会在 yazi 退出后自动 cd 到你最后在 yazi 中浏览的目录，无需手动再 cd。

Q: 如何添加自己的缩写或函数？

直接编辑 ~/.config/fish/config.fish，在对应区块添加即可。修改会在新开终端时生效，或在当前终端执行 source ~/.config/fish/config.fish 立即生效。

# 添加缩写：
abbr -a -- dc 'docker compose'

# 添加函数：
function mkcd
    mkdir -p $argv[1]
    cd $argv[1]
end

Q: 如何备份和迁移这份配置？

核心文件只有 config.fish 和 secrets.fish（不含 API Key）：

# 备份（排除敏感文件和缓存）
cp ~/.config/fish/config.fish ~/backup/
cp ~/.config/fish/completions/*.fish ~/backup/

# 迁移到新机器后，确保安装所有依赖：
# sudo pacman -S fish starship zoxide fzf fd atuin direnv tldr bat yazi eza procs tokei onefetch ouch
